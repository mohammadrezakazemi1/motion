# SQL Server Audit Motion Graphic (23.35s)

A self-contained HTML/CSS motion graphic for the tax-calculation / SQL Server stored-procedure story.

## Preview
Open `index.html` in a modern browser. It animates automatically and loops at 23.35 seconds. Use the on-screen controls to restart, pause/resume, or enter fullscreen.
