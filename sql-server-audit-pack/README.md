## Import and edit
- Import the SVG files directly into DaVinci Resolve or After Effects. If a version of your editor does not handle SVG reliably, convert each to a 1920×1080 PNG first.
- These are background plates, not finished animations; animate scale/position, opacity, glow and parallax in your editor.
- Place the Persian text in a separate layer above the image. Use a dark translucent gradient or a subtle shadow behind text if needed.
- Keep the key subject toward the right edge, leaving a relatively quiet central/left area for captions.
- The pack intentionally contains no baked-in wording, so you can localize and change the script freely.
