# SQL Server Audit Story Pack — Vertical Graphic Edition

**Format:** 1080 × 1920 (9:16), Reels-ready SVG illustrations  
**Style:** full-frame, colorful editorial / dimensional vector scenes with characters, props, UI panels and story-specific visual metaphors. No empty placeholder compositions.

## Shot mapping
- **01-accountant-call.svg — 01 — Accountant calls:** Accountant in a busy finance office answering a phone, ledgers, calculator, monitors, urgent incoming call; full-bleed 9:16 editorial 3D-vector illustration.
- **02-tax-notice.svg — 02 — Tax notice arrives:** Accountant holding a red urgent tax notice in a finance office, papers and tax folder fill frame.
- **03-unexpected-amount.svg — 03 — Unexpected amount:** Large tax amount surges on a glowing financial dashboard while a worried accountant looks on; full frame.
- **04-company-pressure.svg — 04 — Company under pressure:** Business owner and accountant under pressure at a desk, invoices and a dramatic red falling financial chart.
- **05-three-months-back.svg — 05 — Investigating three months back:** Accountant studying printed reports, calendar pages flipping back three months, highlighted timeline and paper trails.
- **06-stored-procedure-edit.svg — 06 — Tiny stored procedure change:** Close-up developer hands at SQL editor changing a single line in a stored procedure; code panels and database console dominate frame.
- **07-cascade-failure.svg — 07 — Calculations cascade into failure:** Stacked financial calculation tiles breaking apart, red error indicators, tax totals dominoing through linked database nodes.
- **08-forensic-audit.svg — 08 — What changed and why?:** Investigator examining code diff and audit trail with a large magnifying glass; highlighted changed SQL line and timestamps.
- **09-sql-log-manager.svg — 09 — SQL Server Log Manager:** Powerful SQL Server database core connected to audit logs, stored procedures, user actions and monitoring panels; rich isometric technical illustration.
- **10-git-style-history.svg — 10 — Git-like change history:** A version-control timeline for database procedures, multiple commits connected like a glowing branching tree, each commit represented by code cards.

## Use
- Import SVGs into After Effects or DaVinci Resolve (SVG support may depend on workflow; rasterize to PNG at 1080×1920 if needed).
- Add parallax, camera push-ins, depth blur, glows and small animated elements for motion.
- Keep key faces and visual information centered in the 9:16 safe area.

These are editable vector illustrations rather than photographs. The goal is a story-specific illustrated pack, not blank backgrounds or generic decorative panels.
