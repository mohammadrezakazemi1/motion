# SQL Server Audit — 3D Motion Graphics Pack

This folder contains transparent, scalable SVG source assets for the motion graphics pack. The downloadable ZIP shared separately contains the ready-to-import transparent PNG illustrations and Persian shot map.

## Asset-to-script map
1. «حسابدار زنگ زده» — `03_accountant_3d.svg`: pop in from left, tiny phone vibration.
2. «مالیاتی که این فصل محاسبه شده...» — `02_tax_document_3d.svg`: document rises; add a cyan scan line.
3. «خیلی بیشتر از انتظاره» — `04_alert_3d.svg`: amber warning snaps in with brief overshoot.
4. «شرکت باید مبلغ بیشتری رو بپردازه» — tax document + alert; alert lands beside the document.
5. «و هیچ‌کس نمی‌دونه چرا» — `09_audit_clock_3d.svg`: rotate slightly, then freeze.
6. «بعد از چند روز بررسی معلوم شد...» — `08_change_timeline_3d.svg`: log cards appear one-by-one.
7. «که سه ماه پیش» — clock; rewind hands and add a 3-month timeline label in After Effects.
8. «یکی یه SP رو تغییر داده» — `06_stored_procedure_3d.svg`: highlight a single line in violet.
9. «و یه تغییر کوچیک» — zoom into the stored-procedure sheet and reveal one changed line.
10. «آروم‌آروم تمام محاسبات مالیاتی رو خراب کرده» — database + gear; pulse out of sync, then warning.
11. «ولی دقیقاً چی رو عوض کرده و چرا؟» — `07_git_version_control_3d.svg`: draw branch paths; add question text separately.
12. «برای همین» — fast 6-frame transition into the solution.
13. «یک لاگ منیجر برای SQL Server ساختم» — server + timeline cards assemble beside it.
14. «هر تغییر رو ثبت می‌کنه» — timeline cards stack sequentially.
15. «مثل Git» — draw branch paths and pop nodes in sequence.
16. «چه کسی، چه زمانی، چه دستوری رو تغییر داده» — accountant + clock + stored-procedure icons in sequence. Add editable WHO / WHEN / WHAT labels separately.

## Style
1080×1920, 30fps. Keep the center clear for subtitles. Use restrained cyan glow, soft shadow and 8–12 frame scale overshoot. These are 3D-inspired transparent illustrations, not editable 3D models.
